# Food Choice Streamlit Prototype

نسخه آزمایشی کاربرمحور برای تست تجربه «چی بپزم؟».

## قابلیت‌های فعلی

- انتخاب اولیه غذاهایی که کاربر معمولاً می‌پزد
- حدود ۴۰ غذای اولیه در چند دسته معقول
- انتخاب هم‌زمان زمان، هزینه، سبک/سنگین و نوع غذا
- نمایش زمان آماده‌سازی، پخت و مجموع با فرمت ساعت/دقیقه
- اولویت دادن به غذاهای معمول کاربر
- انتخاب چند غذای جدید برای امتحان و ورود گهگاهی آن‌ها به پیشنهادها
- رابط فارسی RTL در Streamlit

## اجرا

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

کالری، قیمت دقیق، موجودی خانه و تشخیص خرید در این نسخه عمداً اضافه نشده‌اند و برای مرحله بعد نگه داشته شده‌اند.
