# Food Choice — چی بپزم؟

یک وب‌اپ بسیار سبک و قابل نصب (PWA) برای حذف خستگی انتخاب غذا. برنامه تعداد نفرات را نگه می‌دارد، بر اساس تاریخچه و تنوع هفتگی یک غذا پیشنهاد می‌کند، مواد لازم را متناسب با تعداد نفرات نشان می‌دهد، دستور پخت دارد و وعده‌های پخته‌شده را روی دستگاه در IndexedDB ذخیره می‌کند.

## قابلیت‌های MVP

- انتخاب یک‌ضرب «چی بپزم؟» با پیشنهادهای سریع، متعادل‌تر و اقتصادی
- ذخیره دائمی تعداد نفرات
- مقیاس‌کردن مواد اولیه بر اساس تعداد نفرات
- تاریخچه غذاها در IndexedDB، بدون نیاز به ساخت حساب
- امتیازدهی پیشنهادها بر اساس فاصله از آخرین پخت و جلوگیری از تکرار دسته‌های اخیر
- خلاصه ۷ روز اخیر برای ماهی، حبوبات، سبزیجات و گوشت قرمز
- دستور پخت اختیاری برای هر غذا
- نصب روی Home Screen و کار آفلاین با Service Worker
- بدون dependency سمت کلاینت و بدون build step

> بخش «تعادل این هفته» توصیه پزشکی نیست؛ فقط برای کمک به تنوع غذایی عمومی طراحی شده است.

## اجرا روی کامپیوتر

```bash
npm test
npm run serve
```

بعد `http://localhost:4173` را باز کنید.

## معماری

- `index.html` رابط اصلی
- `styles.css` طراحی mobile-first و RTL
- `js/data.js` کاتالوگ اولیه غذاها
- `js/recommender.js` موتور امتیازدهی و تنوع
- `js/db.js` لایه IndexedDB برای تنظیمات و تاریخچه
- `js/app.js` مدیریت رابط، نصب PWA و تعاملات
- `sw.js` کش آفلاین
- `manifest.webmanifest` نصب PWA
- `test/` تست موتور پیشنهاد

## انتشار روی GitHub Pages

کد انتشار آماده است، اما GitHub اجازه نمی‌دهد `GITHUB_TOKEN` اولین بار Pages را برای یک مخزن فعال کند. برای انتشار فقط یک تنظیم یک‌باره لازم است:

1. در GitHub وارد `Settings` مخزن شوید.
2. بخش `Pages` را باز کنید.
3. در `Build and deployment`، مقدار `Source` را روی `GitHub Actions` بگذارید.
4. سپس از تب `Actions`، workflow با نام `Deploy Pages` را با `Run workflow` اجرا کنید.

بعد از فعال‌شدن Pages، همین workflow تست‌ها را اجرا و نسخه استاتیک PWA را منتشر می‌کند. آدرس معمول پروژه پس از انتشار `https://shahbazi-amir.github.io/Food_choice/` خواهد بود.

## گام‌های بعدی پیشنهادی

1. موجودی مواد داخل خانه و «با چیزهایی که دارم چی بپزم؟»
2. چند پروفایل خانوادگی و همگام‌سازی ابری اختیاری
3. لیست خرید خودکار از مواد کمبود
4. ترجیحات، حساسیت‌ها و غذاهای ممنوع
5. افزودن غذا توسط کاربر و ورود دستور پخت
6. بک‌اند اختیاری Supabase فقط زمانی که همگام‌سازی چند دستگاه لازم شود
